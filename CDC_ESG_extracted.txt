Chatbot Intelligent ESG

Projet de Fin d'Études — Spécifié pour Agent IA (Antigravity)


1. CONTEXTE ET OBJECTIF DU PROJET
Ce projet consiste à développer un chatbot intelligent capable d'analyser des rapports ESG (Environnemental, Social, Gouvernance) en format PDF et de répondre aux questions des utilisateurs en se basant uniquement sur les données contenues dans ces rapports.

1.1 Problème résolu
Un rapport ESG peut contenir 200 à 300 pages. Un analyste doit actuellement lire manuellement l'intégralité du rapport pour trouver une information précise. Ce chatbot permet de poser une question en langage naturel et d'obtenir une réponse immédiate avec la source exacte (numéro de page).

1.2 Utilisateurs cibles

2. ARCHITECTURE TECHNIQUE COMPLÈTE
Le système est composé de 5 modules qui travaillent ensemble dans un pipeline séquentiel.

2.1 Pipeline général
PDF Input → CNN (filtre) → pdfplumber (extraction) → CamemBERT (classification) → ChromaDB (stockage) → Mistral (réponse) → Streamlit (interface)

2.2 Stack technologique

4. MODULE 2 — EXTRACTION DE TEXTE ET TABLEAUX
Ce module extrait le texte des pages identifiées comme ESG par le CNN.

4.1 Extraction du texte normal
import pdfplumber

def extraire_texte(pdf_path, pages_esg):
    textes = []
    with pdfplumber.open(pdf_path) as pdf:
        for num_page in pages_esg:
            page = pdf.pages[num_page]
            texte = page.extract_text()
            if texte and len(texte) > 50:
                textes.append({'page': num_page, 'texte': texte})
    return textes

4.2 Extraction des tableaux
import camelot

def extraire_tableaux(pdf_path, pages_esg):
    pages_str = ','.join(str(p+1) for p in pages_esg)
    tables = camelot.read_pdf(pdf_path, pages=pages_str)
    return [t.df.to_string() for t in tables]

4.3 Segmentation en paragraphes
def segmenter_paragraphes(texte, min_longueur=50):
    paragraphes = texte.split('\n\n')
    return [p.strip() for p in paragraphes if len(p.strip()) > min_longueur]

7. MODULE 5 — CHROMADB (Base vectorielle RAG)
ChromaDB stocke les paragraphes sous forme de vecteurs mathématiques pour permettre une recherche sémantique efficace.

7.1 Concept du RAG
# RAG = Retrieval Augmented Generation
# 1. STOCKER: Paragraphes ESG → vecteurs → ChromaDB
# 2. RÉCUPÉRER: Question → ChromaDB cherche passages similaires
# 3. GÉNÉRER: Passages + Question → Mistral génère réponse

7.2 Code d'initialisation ChromaDB
import chromadb
from chromadb.utils import embedding_functions

client = chromadb.PersistentClient(path='./chroma_db')

sentence_transformer_ef = embedding_functions.SentenceTransformerEmbeddingFunction(
    model_name='paraphrase-multilingual-mpnet-base-v2'
)

collection = client.get_or_create_collection(
    name='esg_rapports',
    embedding_function=sentence_transformer_ef
)

7.3 Code d'insertion des données
def stocker_paragraphes(paragraphes, labels, metadonnees):
    collection.add(
        documents=paragraphes,
        metadatas=[{
            'label': label,
            'page': meta['page'],
            'rapport': meta['rapport'],
            'annee': meta['annee']
        } for label, meta in zip(labels, metadonnees)],
        ids=[f'doc_{i}' for i in range(len(paragraphes))]
    )

7.4 Code de recherche sémantique
def rechercher(question, n_resultats=5, filtre_label=None):
    where = {'label': filtre_label} if filtre_label else None
    resultats = collection.query(
        query_texts=[question],
        n_results=n_resultats,
        where=where
    )
    # Vérifier le score de similarité
    if resultats['distances'][0][0] > 0.7:
        return None  # Pas de résultat pertinent
    return resultats

2. Si l'information n'est PAS dans le contexte → dis 'Information non disponible dans les rapports chargés'

8.3 Code de génération
import ollama

def generer_reponse(question, contexte):
    if not contexte:
        return 'Information non disponible dans les rapports chargés.'
    
    prompt = f'''
    Contexte extrait des rapports ESG:
    {contexte}
    
    Question: {question}
    
    Réponds UNIQUEMENT avec le contexte ci-dessus.
    '''
    
    response = ollama.chat(
        model='mistral',
        messages=[
            {'role': 'system', 'content': SYSTEM_PROMPT},
            {'role': 'user', 'content': prompt}
        ]
    )
    return response['message']['content']

10.1 Fonctionnalités de l'interface

10.2 Code Streamlit principal
import streamlit as st
import requests

st.title('🤖 Chatbot ESG Intelligent')

# Upload PDF
uploaded_file = st.file_uploader('Charger un rapport ESG (PDF)', type='pdf')
if uploaded_file:
    response = requests.post('/upload-rapport', files={'file': uploaded_file})
    st.success('Rapport chargé avec succès!')

# Interface de chat
if 'messages' not in st.session_state:
    st.session_state.messages = []

for msg in st.session_state.messages:
    with st.chat_message(msg['role']):
        st.write(msg['content'])

if question := st.chat_input('Posez votre question ESG...'):
    response = requests.post('/question', json={'texte': question})
    reponse = response.json()['reponse']
    st.session_state.messages.append({'role': 'user', 'content': question})
    st.session_state.messages.append({'role': 'assistant', 'content': reponse})
